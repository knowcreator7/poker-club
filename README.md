# ♠️ Покерный клуб

Telegram-бот и мини-приложение для домашнего покера на фишки.

- `index.html`, `app.css`, `app.js` — приложение. Правки здесь появляются в боте через пару минут.
- `worker.js` — сервер для Cloudflare Workers: бот, API, база D1, напоминания.

Работает круглосуточно и бесплатно: Cloudflare Workers + D1.
